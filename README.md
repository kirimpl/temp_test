# VAYRHEX — Beta 0.6: баланс и демо-монетизация

Рабочее название. Сохранены все исследования, башни и настройки предыдущей версии.

## Баланс
- Бонусы после каждой волны теперь суммируются, не перемножаются между собой.
- Урон +6% (до 4 раз); скорострельность +5% (до 4); дальность +4% (до 3).
- Доход +7% (до 4), горение +15% (до 3), цепь +1 цель (только раз).
- Мгновенные варианты: +35 кредитов и +16 HP. Вариант ремонта скрыт при почти полном здоровье.
- Модули на максимальном уровне исключены из выдачи. Предложения равномерно перемешиваются.
- Баланс предварительный: враги, стоимость башен и экономика ещё требуют плейтестов.

## Тестовая монетизация
- После проигрыша базовые осколки начисляются без рекламы.
- На localhost и *.pages.dev можно симулировать событие rewarded и получить ещё 30% от базовой награды.
- Это тестовый провайдер: рекламы нет, денег разработчику нет, пользователь видит явную отметку «Тест».
- Только событие onRewarded даёт бонус; onOpen/onClose не дают. Повторная выдача блокируется по ID забега.
- Последние 80 подтверждений хранятся в прежнем localStorage corebound-save-v1 для сохранения прогресса.
- Клиентские проверки не защищают от подделки: для релиза понадобятся Yandex SDK, серверные проверки покупок и более надёжные сохранения.
- https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv
