# VAYRHEX — рабочее название (UI 03)

Браузерная Tower Defense с roguelite-модулями; тестовая сборка для телефона и ПК.

> **Важно:** название VAYRHEX используется временно и не прошло официальную проверку товарных знаков. Прежнее название COREBOUND заменено из-за существования одноимённой игры Overcurve. Детали и оставшиеся риски: [IP_AUDIT.md](IP_AUDIT.md).

## Что реализовано

- Три оригинальные геометрические башни, маршруты, волны и боссы.
- Строительство, улучшение и продажа башен; выбор бонусного модуля между волнами.
- Система осколков и усиление ядра в `localStorage`.
- Сенсорное управление, регулировка скорости, процедурно синтезированные звуки и CSS-анимация логотипа.
- Без сторонних звуков, скачанных текстур и сторонних JavaScript-библиотек в активной сборке.

## Файлы

- `index.html` — интерфейс.
- `ui-v03.css` — используемый CSS.
- `game.js` — игровая логика.
- `IP_AUDIT.md` — юридические и платформенные ограничения перед публикацией.
- `.github/workflows/verify.yml` — проверки сборки.

Внутренний ключ сохранений оставлен `corebound-save-v1`, чтобы **не потерять прогресс** игроков, открывавших прототип ранее. Он не используется как видимое название игры.

## Статус выпуска

**Не готово для монетизации или Яндекс Игр.** Потребуются проверка окончательного названия и товарных знаков, интеграция Yandex Games SDK, тесты мобильной сборки и соответствие остальным требованиям площадки.

Репозиторий публичный, но лицензия на свободное использование исходников не предоставлена.
