# VAYRHEX — Beta 0.8

Браузерная Tower Defense с постоянной прогрессией. Рабочее название. Бесплатная тестовая версия для телефона и ПК.

## Исследования — единая карта

В версии 0.8 отдельные списки и вкладки заменены одной связанной картой из **45 узлов**: центральное ядро, общие исследования, пять башен и их специализации. Карта поддерживает перетаскивание, колесо мыши, жест масштабирования двумя пальцами, кнопки +/- и «Вся карта». Выбери узел, чтобы увидеть условия, стоимость, текущий уровень и купить исследование.

Идея масштабируемой сети талантов вдохновлена жанром RPG, без копирования ассетов, интерфейсных экранов и кода других игр.

## Совместимость прогресса

- Сохранены старые ID исследований, стоимость уровней и ключ сохранения `corebound-save-v1`.
- Ранее купленные улучшения и открытые башни сохраняются; новая карта отображает их активными.
- Новые башни «Дуга» и «Рельс» теперь расположены на путях общих исследований. Игрокам, которые уже их открыли, проходить условия заново не требуется.
- Исправлено обновление интерфейса выбранной башни: новая цена, уровень и характеристики отображаются сразу; доступность кнопки пересчитывается после изменения кредитов.

## Структура проекта

- `index.html` — основной экран, меню и игровое поле.
- `ui-v03.css` — существующий игровой интерфейс.
- `game.js` — игровой процесс, экономика и сохранения.
- `atlas-v08.js` — новая карта технологий, навигация и покупки.
- `atlas-v08.css` — оформление единой карты.
- `IP_AUDIT.md` — предварительный аудит интеллектуальных прав.
- `.github/workflows/verify.yml` — автоматическая проверка JavaScript и статических файлов.

## Тесты и публикация

GitHub: `kirimpl/temp_test`, Cloudflare Pages автоматически публикует `main`. Для локального просмотра можно выполнить `python -m http.server 8000` в корне проекта и открыть `http://localhost:8000`.

Яндекс SDK и реальные рекламные/платёжные операции пока **не подключены**. Тестовая награда за рекламу на Cloudflare не является реальным рекламным просмотром. Прежде чем монетизировать, необходимо завершить интеграцию платформы и проверку названия в реестрах товарных знаков.
