# COREBOUND — UI 03

Браузерная Tower Defense с roguelite-модулями. Тестовая сборка для телефона и ПК.

## Прототип

- Три башни, несколько маршрутов, волны противников и боссы.
- Строительство, улучшение и продажа башен, выбор бонусного модуля между волнами.
- Осколки и постоянная прокачка ядра хранятся на устройстве в localStorage.
- Поддержка касаний, мыши, полноэкранного режима, регулировки скорости и звука.

## Что нового в UI 03

- Полностью новый HUD, где приоритет у игрового поля.
- Башни доступны без предварительного выбора площадки: выбери башню, затем коснись свободного узла. Можно и в обратном порядке.
- Минималистичные панели, функциональная типографика, контрастные карточки строительства.
- Обновлённое главное меню, модальное окно усилений и экран результатов.
- Анимированный фирменный знак: внешний квадрат и внутренний квадрат вращаются в противоположные стороны (учёт prefers-reduced-motion).
- Поле и модели врагов, башен и ядра сохранены.

## Cloudflare Pages

Репозиторий: `kirimpl/temp_test`. Production: `main`. Framework: None, build command `exit 0`, output directory `.`. Исходники статического сайта:

- `index.html` — интерфейс,
- `ui-v03.css` — актуальные стили,
- `game.js` — игровая логика.

Файлы `styles.css` и `ui-v02.css` оставлены для истории и больше не подключаются. Подключённые GitHub-автосборки проверяют синтаксис JavaScript и наличие актуальных файлов.

Это ранний прототип, без интеграции Яндекс SDK и реальных покупок/рекламы.
