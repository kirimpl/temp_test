# VAYRHEX — браузерная Tower Defense (Beta 0.4)

VAYRHEX — **временное название**, пока не проведена полноценная проверка товарных знаков. Исходный код и игровая графика прототипа не используют чужие готовые ассеты.

## Новое в Beta 0.4

- В главном меню появились **Настройки** и **Исследования**.
- В настройках работают четыре параметра: громкость фоновой синтезированной музыки, громкость выстрелов/эффектов, максимум одновременно отображаемых снарядов (0–120), прозрачность снарядов (0–100%). Значения немедленно применяются и сохраняются в `localStorage` под ключом `vayrhex-settings-v1`.
- Число видимых снарядов влияет на отрисовку, **не на боевые расчёты**: скрытые выстрелы по-прежнему попадают и наносят урон.
- **9 постоянных исследований** в трёх ветвях — ядро, вооружение, ресурсы. Покупаются за осколки, имеют ранги и зависимости. Бонусы применяются к игровым характеристикам в новых забегах.
- Предыдущее сохранение `corebound-save-v1` намеренно не переименовывалось, чтобы сохранить уже купленные улучшения ядра и накопленные осколки.
- Музыкальный фон синтезируется программно через Web Audio. Никаких чужих звуковых файлов; браузер запускает аудио после нажатия игроком кнопки.

## Запуск без сборки

Выполнить в корне репозитория:

```bash
python -m http.server 8080
```

Затем открыть `http://localhost:8080`. В проекте нет внешних JavaScript-зависимостей.

## Структура

- `index.html` — игровая разметка и меню.
- `ui-v03.css` — актуальное оформление.
- `game.js` — рендер, игровой цикл, настройки, исследования и сохранения.
- `IP_AUDIT.md` — обнаруженные правовые риски и вопросы перед релизом.

## Публикация

Cloudflare Pages связан с `main`: проект без фреймворка; build command `exit 0`, output directory `.`. После отправки нового коммита сайт обновляется автоматически.

### Статус

Это **прототип**, а не версия для публикации на Яндекс Играх. SDK, тестирование производительности и официальная проверка финального названия ещё впереди.
