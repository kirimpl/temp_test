# COREBOUND — прототип 0.1

Бесплатная браузерная игра в жанре Tower Defense + Roguelite. Разрабатывается с прицелом на ПК, мобильный браузер и Яндекс Игры.

## Запуск

- Откройте опубликованную ссылку Cloudflare Pages на телефоне или компьютере.
- Для локального запуска из папки проекта: `python -m http.server 8000`, затем `http://localhost:8000`.

## Содержимое

- `index.html` — структура интерфейса
- `styles.css` — оформление и мобильная адаптация
- `game.js` — игровая логика

Никакой установки зависимостей или сборки не требуется.

## Работает в v0.1

- Три типа башен, строительство, прокачка и продажа
- Волны противников, несколько маршрутов, боссы
- Случайные улучшения после волн
- Постоянная прокачка ядра (localStorage)
- Сенсорное управление, отображение на мобильном экране

Это ранний прототип: Яндекс SDK и реальная монетизация пока не интегрированы.

## Автоматическая публикация в Cloudflare Pages

1. Cloudflare Dashboard → Workers & Pages → Create application → Pages → Connect to Git.
2. Выберите GitHub-репозиторий `kirimpl/temp_test`.
3. Укажите `main` в качестве production branch.
4. Выберите Framework preset: **None**; Build command: `exit 0`; Build output directory: `.` (корень репозитория).
5. Нажмите Save and Deploy.

После привязки изменения в `main` автоматически публикуются по постоянной ссылке Cloudflare Pages. Коммиты в `dev` могут давать отдельные preview deployments — при включённых preview builds.

## Рабочий процесс

- `dev`: разработка и тестовые сборки
- `main`: стабильная демонстрационная версия
- GitHub Actions проверяет синтаксис JS и наличие файлов после коммитов.
- Cloudflare сам запускает публикацию после push (после первоначальной привязки аккаунта).

Не храните пароли/ключи Яндекс Игр или Cloudflare в репозитории.
